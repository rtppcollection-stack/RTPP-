# 🚀 RTPP · Crypto Dashboard, Swap & P2P Calculator

A high-performance, non-custodial Web3 trading and financial analytics terminal built for seamless multi-chain swaps, market analysis, and risk management.

🌐 **Live Demo:** [rtpp.vercel.app](https://rtpp.vercel.app/)

---

## ✨ Key Features

* **🔥 Live Crypto Market Dashboard:** Powered by real-time market data & sparkline charts via CoinGecko.
* **🔄 Multi-Chain & BTC Swap Terminal:** Non-custodial cross-chain token swapping with automated DEX routing (Uniswap V3, PancakeSwap V3, Raydium, SushiSwap, etc.).
* **👛 Multi-Chain Portfolio Tracking:** Track Web3 wallet balances across Base, Ethereum, Solana, and BSC.
* **📊 Professional P2P & Risk Calculator:** Position size and Risk/Reward analysis tools for smart trading decisions.
* **🐋 Whale Radar & NFT Market Tracker:** Monitor large on-chain transactions and trending NFT collections.

---

## 🛠️ Tech Stack

* **Frontend:** React.js / Next.js
* **Styling:** Tailwind CSS / Modern Dark Mode UI
* **Deployment:** [Vercel](https://vercel.com)
* **Market Data:** CoinGecko API
* **DEX Integration:** Uniswap V3 Router, ThorChain / Garden Cross-Chain
